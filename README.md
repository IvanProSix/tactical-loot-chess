# Tactical Loot Chess

Пошаговая тактика 8x8 для 2 игроков по LAN: лут, оружие, пиксель-арт, процедурный звук.

## Запуск
```
npm install
node server.js
```
Сервер выведет ссылки вида `http://192.168.x.x:3000`: откройте одну у себя, вторую отправьте сопернику в той же сети.
Другой порт: `PORT=3001 node server.js` (Windows PowerShell: `$env:PORT=3001; node server.js`).

## Управление
- ЛКМ: выбрать юнита, двигаться (голубые клетки), атаковать (враг в красной рамке)
- ПКМ / Esc: отмена, Enter / Пробел: конец хода, Tab: следующий юнит, M: звук
- Кнопка в карточке юнита: активировать Дробовик / Джетпак / Мину

## Структура
- `server.js`: авторитетный сервер (логика, урон, лут, таймер, фильтрация тумана войны)
- `public/shared.js`: общие правила (LOS по Брезенхэму, BFS, дальности), используются сервером и клиентом
- `public/game.js`: клиент (Canvas, анимации, UI), `public/sprites.js`: спрайты 16x16, `public/sound.js`: синтезатор Web Audio
