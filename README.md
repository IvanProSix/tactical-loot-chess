# Tactical Loot Chess

Пошаговая тактика 8x8 для 2 игроков онлайн: лут, оружие, пиксель-арт, процедурный звук.

## Как играть
Откройте сайт → «Создать комнату» → «Скопировать ссылку» и отправьте её другу (или скажите 4-символьный код).
Друг открывает ссылку (или вводит код в меню, или выбирает комнату в списке «Открытые комнаты»), оба жмут «Готов».
«Тренировка на одном экране» — играть за обе стороны самому.

## Локальный запуск
```
npm install
node server.js
```
Откройте http://localhost:3000. Другой порт: `PORT=3001 node server.js`.

## Хостинг на Render (бесплатный тариф)
Сервер сам пингует свой адрес (`RENDER_EXTERNAL_URL`) раз в 10 минут, чтобы бесплатный инстанс не засыпал.
Отключить: переменная окружения `KEEP_AWAKE=0`. Партии хранятся в памяти — при деплое/перезапуске текущие матчи прерываются.

## База данных и админы (Render → Environment)
- `DATABASE_URL` — строка подключения Postgres (Neon). Без неё прогресс хранится в `data/players.json` (только для локального запуска).
- `ADMIN_NAMES` — ники админов через запятую, например `Ivan,Друг`. **Сначала зарегистрируйте ник в игре, потом добавляйте его сюда**: незарегистрированный ник из списка становится зарезервированным, и зарегистрировать его уже нельзя. У них в меню появляется кнопка «🛠 Админ»: выдача монет, открытие юнитов, сброс таймеров, уровень рудника, выдача и изъятие особых юнитов «Зелёный слоник» и «Ледяной маг» (их нельзя купить или выбить — только получить от админа). Действия пишутся в лог сервера.

## Управление
- ПК: ЛКМ — выбрать юнита, двигаться (голубые клетки), атаковать (враг в красной рамке); ПКМ / Esc — отмена; Enter / Пробел — конец хода; Tab — следующий юнит; M — звук
- Телефон: касание — выбор / ход / атака; кнопка «Отмена» — сброс выбора
- Кнопка в карточке юнита: активировать Дробовик / Джетпак / Мину

## Структура
- `server.js`: авторитетный сервер (комнаты, логика, урон, лут, таймер, фильтрация тумана войны)
- `public/shared.js`: общие правила (LOS по Брезенхэму, BFS, дальности), используются сервером и клиентом
- `public/game.js`: клиент (меню, комнаты, Canvas, анимации, UI), `public/menubg.js`: живой фон меню
- `public/sprites.js`: спрайты 16x16, `public/sound.js`: синтезатор Web Audio (эффекты и музыка меню)
